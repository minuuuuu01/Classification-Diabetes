# Classification-Diabetes
클래스 불균형을 고려하여 당뇨병 환자를 정확히 찾아내는 것(False Negative 최소화)을 최우선 목표로 한 머신러닝 모델 개발 프로젝트입니다.

## 1. 데이터 분할
- **Train : Valid : Test** = 7 : 2 : 1

## 2. 데이터 전처리
- **결측치:** 없음
- **이상치 처리:**
  - **나이:** 기초 통계량 확인 결과 정상 범위(0.08~80)로 판단하여 유지
  - **당화혈색소, 혈당 수치:** 사분위수 기준 이탈 데이터가 100% 양성(당뇨) 클래스이므로 이상치 처리 배제
  - **BMI 지수:** 수치가 높을수록 양성 확률이 높다는 가설 수립. 통계적 상한선(38.43) 초과 값을 모두 38.43으로 치환
- **범주형 변수 인코딩:**
  - **성별 (Gender):** 불가능한 값인 'Others' 범주(총 10만 개 중 15개) 제거 후 Male/Female 레이블 인코딩
  - **흡연 경험 (Smoking History):** 고유값 6개에 대해 원-핫 인코딩 적용

## 3. 모델 학습 및 평가
- **사용 모델:** `RandomForestClassifier`
- **핵심 평가지표 설정:**
  - **Recall (재현율):** 당뇨 환자를 정상으로 오진(False Negative)하는 치명적 위험을 막기 위해 가장 중요한 지표로 설정
  - **Class 1 F1-score:** 음성 클래스(정상)가 압도적으로 많은 불균형 데이터셋이므로, 값이 왜곡되는 0 기준 F1-score나 Macro Avg 대신 양성(당뇨) 클래스의 F1-score에 주목
- **시각화 및 임계값 조정 (검증/테스트 세트 각각 수행):**
  - **Confusion Matrix:** 오류 유형 파악 및 FN 감소 중점 확인
  - **ROC / AUC:** 곡선 및 스코어 시각화
  - **임계값 조정:** 단순히 높은 F1-score만 보지 않고, Precision과 Recall 간의 Trade-off를 고려해 둘의 차이가 최소화되도록 최적화

## 4. 교차 검증 및 하이퍼파라미터 튜닝
- **교차 검증 (Cross Validation):**
  - 클래스 불균형을 고려하여 `StratifiedKFold` (5-Fold) 적용
  - 점수를 높이기 위한 튜닝 목적이 아닌, 모델이 특정 데이터(Train)에만 과적합되지 않고 어떤 데이터가 와도 일관된 성능을 내는지(Robustness) 확인하는 '검진 도구'로 활용
- **하이퍼파라미터 튜닝:**
  - `GridSearchCV`를 활용하여 튜닝과 교차 검증을 동시에 수행
- **최종 결과:**
  - **최고 F1-Score:** 0.8011
